## Was passiert als nächstes?

1. **Du schickst** diesen ausgefüllten Steckbrief an den Programmier-Verantwortlichen
2. **Wir prüfen** die Angaben und klären eventuelle Rückfragen
3. **Wir programmieren** das Tool (typischerweise 1-3 Tage je nach Umfang)
4. **Du bekommst** einen Testlink zur Freigabe
5. **Nach Freigabe** geht das Tool live
